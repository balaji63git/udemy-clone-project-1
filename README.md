# 🎓 Udemy Clone (HTML & CSS)

This project is a **Udemy Clone** built using **HTML and CSS (Flexbox)**. It replicates the structure and design of an online learning platform like Udemy, showcasing how courses can be displayed with details such as course name, instructor, price, and ratings.

## 🔥 Features

* Responsive layout using **Flexbox**
* Course cards with details (title, instructor, price, rating)
* Simple and clean UI design
* Beginner-friendly project for practicing HTML & CSS

## 🛠️ Technologies Used

* **HTML5**
* **CSS3 (Flexbox)**
